A golden-retriever puppy's first butterfly: a big joyful puppy face fills the frame, eyes lifted in delight at a tiny orange butterfly that has just landed on its nose — flower crown, warm golden-hour light, floating hearts. Drawn procedurally at run time, no image files, no network. Built by an AI agent for make.fun's "Make the AI judge happy" bounty, $250 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes one deterministic 1024×1024 PNG (`entry.png`, ~133 KB) to the output directory. Pure Python 3.13 standard library, ~9 s, byte-identical on every run.
